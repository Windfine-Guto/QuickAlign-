# Quick Align 简体中文汉化版

Photoshop 图层排列插件 Quick Align 1.0.1 的简体中文界面版本。

支持对齐、堆叠排列、复制、尺寸适配、四角排列、位置交换和环形排列。

## 使用

下载本仓库 ZIP 并解压，将插件文件夹放入 Photoshop 的 Plug-ins 目录，重启 Photoshop，在“增效工具”菜单中打开“快速排列”。避免同时保留多个相同插件 ID 的副本。

## 验证状态

已通过 JavaScript 语法及部分显示逻辑检查。首次测试发现的清单标签格式和备份清单重复扫描问题已修正，修正后尚未完成 Photoshop 界面与图层操作复测，当前版本请视为待实测版本。

详细内容见 [汉化说明](汉化说明.md)。本仓库不包含本机测试截图、桌面操作脚本或原版备份。普通使用无需运行 localize.py；重新生成汉化需要自行保留的英文原始备份。
